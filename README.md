# gauravskumar13.github.io

Source of my portfolio site: **https://gauravskumar13.github.io**

I'm Gaurav, an M.Sc. Data Science student at TU Dortmund. Before that, I spent three years as a backend engineer at Tata Digital (Tata Neu). The site covers my work experience, projects and skills, and links to my CV.

## What's in this repository

| File | Purpose |
|---|---|
| `index.html` | The whole site in one file: HTML, CSS, JavaScript, fonts and the QR-code library. It makes no requests to other servers. |
| `Gaurav_Kumar_CV.pdf` | My full CV, served by the "Download CV" button. |
| `photo.jpg` | Profile photo shown in the "At a glance" card. |
| `og.png` | Preview image shown when the link is shared. |

## Features

- Light and dark mode, following the device setting by default
- Animated SVG diagrams for each project, showing what the system does
- Expandable work history, project filters and a skills explorer that links each skill to where I used it
- QR code for sharing the page at career fairs
- Works without any build step; GitHub Pages serves `index.html` directly
